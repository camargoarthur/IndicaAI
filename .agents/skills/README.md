# Espaço para skills locais

Não há SKILL.md personalizado nesta pasta. É intencional: regras atuais são instruções do projeto e templates, sem procedimento recorrente adicional que justifique skill.

Quando houver necessidade demonstrada, use o criador disponível no Codex: pasta por skill, SKILL.md com name/description, procedimento específico, recursos necessários e validação real. Não depender de caminhos globais desta máquina.

[Orientação completa](../../docs/SKILLS.md). Não copiar arquivos de plugins externos para aparentar instalação.
