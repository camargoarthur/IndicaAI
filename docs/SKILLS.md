# Habilidades para manutenção

Usar as skills realmente disponíveis na sessão, lendo as instruções pertinentes. O projeto não depende de uma skill instalada para compilar ou executar.

Para implementação, priorizar planejamento, testes e verificação compatíveis com a tarefa. Para design, utilizar orientação de UX/UI quando disponível. Não instalar plugins, copiar seus arquivos ou criar skills que apenas repitam AGENTS.

Na organização B14 não foi identificada uma skill específica de software engineer no catálogo atual. A revisão foi realizada diretamente sobre os arquivos, referências e ferramentas existentes, sem alegar uso dessa skill.
