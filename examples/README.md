# Exemplos CSV — PROPOSTOS

Ilustram o [contrato candidato](../docs/architecture/CSV_CONTRACT.md), não formato aprovado ou importação executável. Não carregar como dados reais: o aplicativo não existe.

tags-proposta.csv: IDs/grupos fictícios precisam existir ou ser resolvidos conforme contrato. Um nome inclui ; entre aspas. Campo vazio da segunda tag: proposta é preservar se existente, rejeitar se nova sem nome.

associacoes-proposta.csv: primeiro par só será válido se referências existirem e forem compatíveis. Segundo é intencionalmente incompatível se obra-livro-demo for livro e tag-mundo-aberto só se aplicar a jogos. Serve para discutir sucesso parcial, não comprovar importador.

UTF-8, cabeçalho, ; externo e | interno são convenções propostas. Anime não é mídia. Não há CSV pessoal nem exportação do produto.
